# Photos Folder

Place your wedding photos here. Recommended formats and sizes:

## Hero Image
- Filename: `hero.webp` (or `hero.jpg`)
- Recommended size: 1920x1080 or larger
- Keep under 400KB for performance

## Gallery Images
- Filenames: `gallery-01.webp`, `gallery-02.webp`, etc.
- Recommended size: 1200x800 or similar aspect ratio
- Keep under 250KB each for performance

## Tips
- Use WebP format for best compression
- Optimize images before uploading (tools: squoosh.app, tinypng.com)
- Consider different aspect ratios for visual interest
- Include a mix of couple photos and Montenegro scenery
